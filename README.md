# Reder Prediction

> This project aims to develop a predictive model to accurately forecast customer churn for Reder Telecommunications.

## Problem definition
Customer churn prediction enables proactive interventions to improve retention, reduce revenue loss, and enhance customer satisfaction.

## Tools used
1. python 3.10.11
2. pandas
3. numpy
4. matplotlib
5. scikit-learn
6. seaborn
7. ipykernel
8. fastapi
9. uvicorn
10. python-multipart
11. ipykernel

## Approach
1. Data Cleaning & Normalisation – Handled missing values and standardised numerical features.

2. RFM Analysis – Analyzed Recency, Frequency, and Monetary metrics to understand customer behavior.

3. Exploratory Data Analysis (EDA) – Visualised patterns and correlations using matplotlib and seaborn.

4. Feature Engineering – Created relevant features to improve model performance.

5. Model Training – Built and evaluated machine learning models for churn prediction using scikit-learn.

Deployment – Developed a FastAPI endpoint (/churn-predict) to serve the trained model for real-time churn predictions.
